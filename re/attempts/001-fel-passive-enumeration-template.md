# FEL passive enumeration template

Purpose: provide the required public record shape before the first manual FEL enumeration.

This template is not an executed attempt.
The real record must be generated by `../scripts/capture-fel-enumeration.sh` after manual FEL entry.

## Required review

Confirm the output contains only the two permitted commands.
Redact any SID, serial number, or other unique identifier before publication.
Record a failed query exactly as returned after identifier review.
